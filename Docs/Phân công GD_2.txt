TÀI LIỆU PHÂN CÔNG NHIỆM VỤ GIAI ĐOẠN 2: LẬP TRÌNH GIAO DIỆN & BACKEND

I. QUY ĐỊNH CHUNG

Dữ liệu hiển thị trên giao diện: Bắt buộc sử dụng cấu trúc JSON mẫu đã cung cấp.

Quy chuẩn UI: Sử dụng các biến màu sắc và font chữ dùng chung, tuyệt đối không hardcode màu riêng lẻ.

Quy trình làm việc: Chạy lệnh git pull origin main để cập nhật Base code trước khi làm việc. Bắt buộc tạo file code trong đúng thư mục đã quy định (lib/screens, lib/constants...).

II. PHÂN CÔNG CHI TIẾT

1. TẠ ĐỨC DƯƠNG (Nhóm trưởng)

Nhánh làm việc: main

Nhiệm vụ Frontend (Flutter):

Khởi tạo Base code project Flutter.

Thiết lập cấu trúc thư mục chuẩn (screens, widgets, constants, models, services).

Khởi tạo file app_routes.dart để quản lý điều hướng (Routing).

Tạo file và lập trình UI: login_screen.dart, register_screen.dart (Đăng nhập / Đăng ký).

Nhiệm vụ Backend (ASP.NET & SQL Server):

Thiết kế toàn bộ Lược đồ Cơ sở dữ liệu trên SQL Server.

Khởi tạo project ASP.NET Web API.

2. LÊ THỊ QUỲNH TRANG

Nhánh làm việc: feature/trang-ui-home

Nhiệm vụ tạo file & Lập trình UI:

Tạo file lib/constants/app_style.dart: Khai báo toàn bộ mã màu và quy chuẩn UI/UX.

Tạo file lib/screens/home_screen.dart: Code UI Màn hình Dashboard (Hiển thị biểu đồ tròn tiến độ uống nước, tổng calo tiêu thụ, danh sách bài tập).

Tạo file lib/screens/water_calorie_form.dart: Code UI Form nhập liệu lượng nước và calo.

Nhiệm vụ Logic:

Cài đặt thuật toán tính toán chỉ số BMI.

3. NGUYỄN THỊ TRINH

Nhánh làm việc: feature/trinh-ui-form

Nhiệm vụ tạo file & Lập trình UI:

Tạo file lib/screens/profile_setup_screen.dart: Code UI Màn hình Hồ sơ cá nhân (Form nhập Chiều cao, Cân nặng, Mục tiêu sức khỏe).

Tạo file lib/screens/daily_log_screen.dart: Code UI các Form ghi nhận nhật ký sinh hoạt hằng ngày.

Tạo file lib/screens/stats_screen.dart: Code UI Màn hình Thống kê và xử lý tích hợp thư viện hiển thị Biểu đồ (Chart) cân nặng/calo.
